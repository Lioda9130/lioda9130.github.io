# Neon District 5.0 — Planning workspace

**This folder is the shared discussion space for the owner, Codex and ChatGPT.**

- [NEON_DISTRICT_5_ROADMAP.md](./NEON_DISTRICT_5_ROADMAP.md) — vision, technical milestones, quality gates and acceptance criteria.
- [CODEX_REVIEW.md](./CODEX_REVIEW.md) — Codex's technical feedback and suggested first pull request.
- [AGENTS.md](../AGENTS.md) — repository-level instructions for Codex.
- [GitHub Issue template](../.github/ISSUE_TEMPLATE/neon-district-5-review.md) — create an issue for asynchronous discussion after pushing the files.

## Suggested workflow

1. Push these files to your repository with a small docs-only commit.
2. Ask Codex: “Read AGENTS.md and planning/NEON_DISTRICT_5_ROADMAP.md. Validate latest code, edit planning/CODEX_REVIEW.md with technical feedback, and propose a minimal PR. Don't implement the full plan yet.”
3. Open a GitHub Issue using the **Neon District 5.0 — Codex design review** template and link subsequent PRs.
4. Share the GitHub Issue or review file with ChatGPT for further refinement; the owner decides priorities.

No portfolio changes, 3D model modifications or live website behavior changes are included in this planning package.
